# Camp Platform Marketing

이 폴더는 `camp-platform`의 마케팅, 출시 메시지, 홍보 채널, SEO/콘텐츠 전략을 따로 관리하는 작업 공간이다. 앞으로 마케팅 관련 아이디어, 문구, 실험 결과, 채널별 운영안은 이 폴더 아래에 추가한다.

## 현재 포지셔닝

여러 체험단 플랫폼의 모집글을 지역, 카테고리, 마감일, 제공내역 기준으로 한 번에 비교하는 체험단 검색 사이트다. 맛집, 뷰티, 생활 체험단을 빠르게 찾고 원문 신청 페이지로 이동할 수 있게 한다.

현재는 Supabase quota 제한 때문에 회원/DB 의존 기능을 강하게 밀기보다, 정적 캠페인 snapshot 기반의 웹 검색 도구로 홍보하는 편이 안전하다.

## 출시 리스크 메모

- Vercel 정적 웹 배포 리스크는 낮다.
- Supabase `exceed_egress_quota` 제한이 풀리기 전까지 로그인, 저장, DB sync, analytics 같은 DB 의존 기능은 제한될 수 있다.
- 크롤 데이터 특성상 좌표 누락, 중복, 원문 변경, 플랫폼 차단 가능성이 있다.
- 원문 신청 페이지에서 최종 조건을 확인하도록 안내하는 문구를 유지한다.
- 개인정보 처리방침, 문의 채널, 삭제 요청 대응 기준은 홍보 확대 전에 다시 점검한다.

## 우선 홍보 채널

1. 검색 유입
   - 핵심 키워드: `체험단 사이트`, `블로그 체험단`, `인스타 체험단`, `서울 맛집 체험단`, `오늘 마감 체험단`, `디너의여왕 체험단 모아보기`
   - 다음 개발 후보: 지역별, 카테고리별, 마감임박 indexable 랜딩 페이지

2. 네이버 블로그
   - 콘텐츠 주제: 체험단 사이트 비교, 서울 맛집 체험단 찾는 법, 블로그 체험단 신청 기준
   - 글마다 사이트 링크는 자연스럽게 1회 중심으로 배치한다.

3. 네이버 카페/커뮤니티
   - 홍보글보다 무료 도구 공유와 피드백 요청 톤으로 접근한다.
   - 예시: "여러 체험단 플랫폼을 지역/카테고리/마감일로 한 번에 보는 검색 페이지를 만들었습니다. 아직 베타라 피드백 받습니다."

4. 인스타그램, 릴스, 스레드
   - 짧은 콘텐츠 주제: 오늘 마감 체험단 찾는 법, 맛집 체험단 30초 검색, 체험단 신청 전 확인할 3가지
   - 링크는 프로필 또는 고정 댓글에 둔다.

5. 직접 피드백
   - 체험단을 실제로 하는 사람 20명에게 먼저 써보게 한다.
   - 질문은 "찾기 쉬웠나", "신청하고 싶은 게 있었나", "안 믿기는 부분이 있었나" 세 가지로 제한한다.

## 기본 홍보 문구

여러 체험단 플랫폼의 모집글을 지역, 카테고리, 마감일, 제공내역 기준으로 한 번에 비교하는 체험단 검색 사이트입니다. 맛집/뷰티/생활 체험단을 빠르게 찾고 원문 신청 페이지로 이동할 수 있습니다.

## 운영 원칙

- 대규모 광고 집행 전에는 베타 공개, 검색, 블로그, 커뮤니티 중심으로 검증한다.
- 회원 기능보다 "빠르게 찾는 검색 도구" 가치를 먼저 검증한다.
- 홍보 문구는 실제 기능 범위를 넘겨 과장하지 않는다.
- 플랫폼 원문, 제공내역, 모집 상태는 최종 확인이 필요하다는 점을 명확히 한다.
- 채널별 실험 결과는 날짜와 함께 이 폴더 아래에 기록한다.
