# [프로젝트 기획안] 개인용 퀀트 트레이딩 시스템 (Mini-Hedge Fund) 구축 v1.0

## 1. 시스템 개요 및 아키텍처 (Architecture)
본 시스템은 감정을 배제하고 100% 데이터 기반으로 작동하는 자동화 트레이딩 봇을 구축하는 것을 목표로 함. 헤지펀드의 4대 기둥을 모듈화하여 독립적으로 운영함.

*   **주력 언어:** Python 3.10+ (데이터 처리 및 머신러닝 생태계 최적화)
*   **증권사 API:** 한국투자증권 Open API (Linux 환경 지원, REST/Websocket 제공으로 키움증권 대비 시스템 구축 용이)
*   **서버 호스팅:** AWS EC2 (안정성을 위해 24시간 가동되는 클라우드 환경)
*   **데이터베이스:** 
    *   시계열 데이터: TimescaleDB (PostgreSQL 기반) 또는 로컬 Parquet 파일
    *   메타 데이터 및 로그: SQLite 또는 MongoDB

## 2. 모듈별 상세 설계 (Core Modules)

### Phase 1: 데이터 파이프라인 구축 (Data Ingestion)
모든 전략의 뼈대가 되는 과거 데이터(Backtest용)와 실시간 데이터(Live용)를 적재하는 시스템.

*   **수집 소스:**
    *   가격 데이터: Yahoo Finance (과거 일봉), 증권사 API (실시간 틱/분봉)
    *   재무 데이터: OpenDart API (전자공시 재무제표 긁어오기)
*   **저장 구조:** 
    *   속도가 생명인 가격 데이터는 Pandas DataFrame 처리 후 `parquet` 포맷으로 압축 저장.
*   **자동화 (Crontab/Airflow):** 매일 장 마감 후 오후 4시에 전 종목 종가 및 거래량을 스크래핑하여 DB를 자동 업데이트하는 배치(Batch) 스크립트 작성.

### Phase 2: 알파 모델링 및 백테스트 엔진 (Research & Backtest)
아이디어를 검증하고 수학적 우위를 증명하는 연구소 역할. **이 모듈에서는 절대 실제 주문이 나가지 않음.**

*   **백테스트 프레임워크:** `Backtrader` 또는 `VectorBT` 라이브러리 사용.
*   **구현할 핵심 로직 (예시: 롱숏 모멘텀 전략):**
    1.  유니버스 선정: 코스피/코스닥 시가총액 상위 200종목.
    2.  팩터 계산: 최근 20일 이동평균선 이격도, 거래량 급증 여부 계산.
    3.  시그널 생성: 이격도가 낮고 기관 수급이 들어온 상위 10종목 롱(매수).
*   **성과 검증 지표:** 
    *   CAGR (연평균 수익률), MDD (최대 낙폭), 샤프 지수(Sharpe Ratio)를 시각화하여 산출. (수수료 0.015% 및 슬리피지 0.2%를 반드시 로직에 포함해 보수적으로 테스트할 것)

### Phase 3: 트레이딩 실행 시스템 (Execution Engine)
백테스트에서 검증된 시그널을 받아 실제 증권사 서버로 주문(Order)을 쏘는 모듈.

*   **Websocket 연결:** 호가창 데이터를 1초 단위로 받아오기 위해 증권사 API와 웹소켓(Websocket) 연결 유지.
*   **주문 분할 로직 (TWAP 흉내 내기):** 
    *   목표 매수 금액이 1,000만 원일 경우, 시장가로 한 번에 사지 않음.
    *   200만 원씩 5번에 나누어 3분 간격으로 분할 매수하는 '알고리즘 주문' 함수 구현 (슬리피지 최소화).
*   **상태 동기화:** 내 계좌의 실제 잔고와 프로그램 내부의 가상 잔고가 일치하는지 10분마다 크로스 체크(Reconciliation).

### Phase 4: 리스크 관리 모듈 (Risk Management & Kill Switch)
예상치 못한 시스템 버그나 폭락장으로부터 파산을 막는 최후의 보루.

*   **일일 손실 한도 (Daily Drawdown Limit):** 
    *   하루 계좌 총자산 대비 -3% 도달 시, 즉시 **모든 미체결 주문을 취소하고 보유 종목을 전량 시장가 매도**하는 킬 스위치(Kill Switch) 작동.
    *   당일 매매 기능 강제 정지 (다음 날까지 프로그램 락다운).
*   **텔레그램(Telegram) 봇 알림:**
    *   매수/매도 체결 내역, 계좌 수익률, 에러 발생 시 개발자의 스마트폰 텔레그램으로 실시간 메시지 전송.

## 3. 개발 마일스톤 (Action Plan)

*   **[Week 1-2] 인프라 세팅:** AWS 서버 세팅, 한국투자증권 API 발급 및 접속 테스트, 주가 데이터 수집 스크립트 완성.
*   **[Week 3-4] 백테스트 환경:** Backtrader 연동, 기본 이동평균선 전략을 이용한 백테스트 코드 구현 및 MDD 추출 성공.
*   **[Week 5-6] 실행 엔진 & 리스크 관리:** 모의투자 계좌를 통한 자동 매수/매도 API 연동, 텔레그램 알림 봇 연동, 킬 스위치 테스트.
*   **[Week 7] 라이브 테스트:** 실제 계좌(소액 100만 원) 연동, 1주일간 시스템 버그 모니터링.
*   **[Week 8~] 알파 고도화:** 본격적인 퀀트 전략(재무 팩터, 머신러닝) 개발 및 모델 교체.
