# 다른 컴퓨터용 짧은 체크리스트

작성 기준일: 2026-04-24

이 문서는 `camp-platform`, `티스토리 자동화 ing`, `네이버 자동화 ing`를 다른 컴퓨터에서 다시 작업할 때 필요한 최소 체크리스트만 모아둔 짧은 버전입니다.

## 공통 원칙

- 코드는 카톡보다 `git clone` 또는 `git pull`로 받기
- 비밀값은 Git에 없으므로 새 컴퓨터에 다시 넣기
- `node_modules`, `.venv`, `__pycache__`, 로그는 복사하지 말고 새 컴퓨터에서 다시 만들기
- 로그인 세션은 가능하면 새 컴퓨터에서 다시 로그인하기

---

## 1. `camp-platform`

### 준비

- Node.js `20.x` 설치
- 저장소 clone

### 체크리스트

1. `camp-platform` 폴더로 이동
2. `npm install`
3. `.env` 작성
4. 필요하면 Vercel 재연결
5. `npm run dev` 또는 `npm run build`

### Git에 안 오는 것

- `.env`
- `.vercel/`
- `node_modules/`
- `dist/`
- `.cache/`

### 새 컴퓨터에 다시 넣어야 하는 것

- Supabase 값
- Kakao 키
- 각 플랫폼 쿠키/토큰/로그인 정보

### 메모

- 코드 작업만이면 카톡 이동 불필요
- 실행까지 하려면 `.env`는 반드시 다시 넣어야 함

---

## 2. `티스토리 자동화 ing`

### 준비

- Python `3.12+` 설치
- 저장소 clone

### 체크리스트

1. `티스토리 자동화 ing` 폴더로 이동
2. `python -m venv .venv`
3. `.venv\Scripts\pip install -r requirements.txt`
4. `.env` 작성
5. `.\scripts\run_chatgpt_web.ps1` 실행
6. 필요하면 ChatGPT/Tistory 다시 로그인

### Git에 안 오는 것

- `.env`
- `.venv/`
- `runtime/`
- `__pycache__/`
- 일부 로컬 CSV

### 새 컴퓨터에 다시 넣어야 하는 것

- `TISTORY_ID`
- `TISTORY_PASSWORD`
- `COUPANG_ACCESS_KEY`
- `COUPANG_SECRET_KEY`
- `COUPANG_SUB_ID`
- `COUPANG_API_ENABLED`

### 메모

- 코드만이면 카톡 이동 불필요
- 실행까지 하려면 `.venv` 재생성 + `.env` 재작성 필요
- 기존 로그인 상태까지 그대로 쓰려면 `runtime/` 복사 대신 새 로그인 권장

---

## 3. `네이버 자동화 ing`

### 준비

- Python 설치
- Chrome 설치
- 저장소 clone

### 체크리스트

1. `네이버 자동화 ing` 폴더로 이동
2. `pip install -r "네이버 블로그 글쓰기\\개발환경설정파일\\requirements.txt"`
3. `NAVER_ID`, `NAVER_PASSWORD` 설정
4. 필요하면 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 설정
5. Chrome에서 네이버/Gemini 다시 로그인
6. `run_scheduled_post.ps1`, `run_refresh_schedule.ps1`의 Python 경로 확인

### Git에 안 오는 것

- `네이버 블로그 글쓰기/.env`
- Chrome 로그인 프로필
- 로그 폴더
- `__pycache__`

### Git으로 같이 오는 것

- `products_db.csv`
- 자동발행 상태 JSON
- 실행 스크립트들

### 새 컴퓨터에 다시 넣어야 하는 것

- 네이버 계정 정보
- 텔레그램 정보
- Chrome 로그인 상태

### 메모

- 코드와 일부 상태 파일은 Git으로 옮겨짐
- 로그인까지 바로 이어가려면 Chrome 프로필 복사가 필요할 수 있음
- 가장 안전한 방식은 새 컴퓨터에서 다시 로그인

---

## 진짜 짧은 요약

- `camp-platform`: `npm install` + `.env` 다시 작성
- `티스토리 자동화 ing`: Python 설치 + `.venv` 새로 생성 + `.env` 다시 작성
- `네이버 자동화 ing`: Python/Chrome 설치 + 패키지 설치 + 계정정보 재설정 + Chrome 재로그인 + Python 경로 확인
