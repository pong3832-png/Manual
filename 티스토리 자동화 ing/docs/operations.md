# 운영 계획

## 하루 발행 구조

하루 목표 발행량은 총 10개다.

- 일상글: 5개
- 쿠팡 파트너스 광고글: 5개

일상글은 블로그의 자연스러운 활동성, 체류 시간, 신뢰도를 만드는 역할을 한다. 광고글은 쿠팡 파트너스 전환을 직접 목표로 한다.

## 쿠팡 파트너스 광고글 구조

광고글은 다음 형식을 우선한다.

- 2개 상품 비교글
- 3개 상품 비교글
- TOP 2 추천글
- TOP 3 추천글
- 상황별 추천글

광고글 1개에 들어가는 쿠팡 상품 수는 최소 2개, 최대 3개로 제한한다. 상품 수가 너무 많으면 독자의 선택 피로가 커지고, 너무 적으면 비교형 콘텐츠로서 설득력이 약해진다.

## 상품 데이터 흐름

상품은 사용자가 직접 선별한다.

저장 위치:

```text
products_db_category
```

상품 데이터에는 가능하면 다음 정보를 포함한다.

- 카테고리
- 상품명
- 쿠팡 링크 또는 파트너스 링크
- 가격대
- 핵심 장점
- 아쉬운 점
- 추천 대상
- 비교 포인트
- 계절성
- 비고

## 글 작성 흐름

글은 자동 API 작성이 아니라 웹 ChatGPT를 활용한다.

기본 흐름:

1. 상품 DB에서 글에 사용할 상품 2-3개를 고른다.
2. 프롬프트를 만든다.
3. 웹 ChatGPT에 프롬프트를 입력한다.
4. 제목, HTML 본문, 해시태그, 사진 제안을 받는다.
5. 티스토리 HTML 편집기에 붙여넣는다.
6. 발행 결과를 기록한다.

## ChatGPT 산출물

ChatGPT가 생성해야 하는 결과물은 다음이다.

- 제목
- 티스토리용 HTML 본문
- 해시태그
- 사진 또는 이미지 제안
- 쿠팡 파트너스 고지 문구

## 광고글 작성 원칙

- 첫 문단은 독자의 문제를 바로 짚는다.
- 상품명만 나열하지 않고 상황별 선택 기준을 먼저 제시한다.
- 2-3개 상품은 명확한 차이가 있어야 한다.
- 각 상품마다 추천 대상과 피해야 할 대상을 함께 적는다.
- 구매 유도는 강압적으로 하지 않고 선택을 도와주는 톤으로 쓴다.
- 쿠팡 파트너스 고지 문구는 반드시 포함한다.
