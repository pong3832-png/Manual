================================================================
   네이버 블로그 서로이웃 자동 신청 프로그램 - 사용 설명서
================================================================

안녕하세요! 프로그램을 구매해주셔서 감사합니다.
아래 순서대로 따라하시면 바로 사용하실 수 있습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 1단계. 폴더 구성 확인
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

전달받은 압축 파일을 풀면 아래 파일들이 있습니다:

  📁 서로이웃 자동화/
  ├── 서로이웃 크몽.exe    ← 프로그램 본체
  ├── chromedriver.exe      ← 크롬 드라이버 (필수!)
  └── 사용설명서.txt        ← 이 파일

⚠️ 중요: "서로이웃 크몽.exe"와 "chromedriver.exe"는
        반드시 같은 폴더에 있어야 합니다!


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 2단계. 크롬 브라우저 & 드라이버 버전 맞추기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이 프로그램은 "구글 크롬" 브라우저를 자동 조작합니다.
크롬이 없다면 먼저 설치해주세요.

※ chromedriver 버전은 내 크롬 버전과 일치해야 합니다!

[내 크롬 버전 확인 방법]
  1) 크롬 브라우저 실행
  2) 주소창에 chrome://version 입력 후 Enter
  3) 맨 위에 "Google Chrome" 옆 숫자 확인
     예시: 136.0.7103.92

[chromedriver 다운로드]
  1) 아래 사이트 접속:
     https://googlechromelabs.github.io/chrome-for-testing/
  2) "Stable" 항목에서 내 크롬 버전과 같은 번호 찾기
  3) chromedriver → win64 다운로드
  4) 압축 풀어서 chromedriver.exe를 이 프로그램과 같은 폴더에 덮어쓰기

⚠️ 크롬이 자동 업데이트되면 chromedriver도 다시 받아야 합니다.
   프로그램 실행 시 "드라이버 로드 실패" 에러가 나면
   위 과정을 다시 해주세요.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 3단계. 프로그램 실행
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1) "서로이웃 크몽.exe"를 더블클릭하여 실행
     → 프로그램 창이 나타납니다.

  ※ 윈도우에서 "알 수 없는 게시자" 경고가 뜰 수 있습니다.
     "추가 정보" → "실행" 을 눌러주세요.
     (정상적인 프로그램이며, 코드서명이 없어서 나오는 메시지입니다.)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 4단계. 정보 입력
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

프로그램 창에 아래 내용을 입력합니다:

  ① 네이버 아이디   : 로그인할 네이버 ID
  ② 네이버 비밀번호 : 로그인할 네이버 비밀번호
  ③ 검색 키워드     : 서로이웃을 찾을 검색어
                       예시: 일상, 맛집, 육아, 요리
  ④ 신청 목표 인원수: 숫자만 입력 (예: 30)
  ⑤ 신청 메시지     : 서로이웃 신청 시 보낼 메시지
                       (기본 메시지가 미리 입력되어 있습니다)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 5단계. 작업 시작
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1) 모든 정보를 입력한 뒤 "작업 시작" 버튼 클릭
  2) 크롬 브라우저가 자동으로 열립니다
  3) 네이버 로그인 페이지에서 자동으로 아이디/비밀번호 입력

  ⚠️ 캡차(보안문자) 또는 2단계 인증이 뜨면
     브라우저에서 직접 해결해주세요!
     (최대 5분 대기 후 자동으로 다음 작업 진행)

  4) 로그인 성공 → 검색 → 블로그 탭 이동 → 서로이웃 자동 신청
  5) 목표 인원수만큼 신청이 완료되면 자동 종료됩니다


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 6단계. 작업 중지 (선택사항)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  작업 도중 중지하고 싶으면 "작업 중지" 버튼을 클릭하세요.
  현재 처리 중인 블로거까지만 완료하고 안전하게 종료됩니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 로그창 안내
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

프로그램 하단의 로그창에서 실시간 진행 상황을 확인할 수 있습니다:

  [+] ✅ : 신청 성공
  [-]    : 패스 (이미 이웃, 신청 불가 등)
  [!] ⚠️ : 에러 발생 (자동으로 다음으로 넘어감)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
❓ 자주 묻는 질문 (FAQ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1. "드라이버 로드 실패" 에러가 나요
  → chromedriver.exe가 프로그램과 같은 폴더에 있는지 확인
  → 크롬 버전과 chromedriver 버전이 일치하는지 확인
  → 2단계를 다시 진행해주세요

Q2. 로그인이 안 돼요
  → 캡차가 뜨면 브라우저에서 직접 해결해주세요
  → 2단계 인증(OTP 등)도 직접 인증해주세요
  → 5분 내에 인증하지 않으면 시간 초과됩니다

Q3. "이웃추가 버튼이 없습니다" 가 자주 나와요
  → 정상입니다. 비공개 블로그이거나 이웃추가를 막아놓은
     블로거는 자동으로 패스합니다.

Q4. 프로그램 실행 중 크롬 창을 건드려도 되나요?
  → 가급적 건드리지 마세요!
     프로그램이 자동으로 창을 조작하고 있으므로
     직접 클릭하면 오류가 발생할 수 있습니다.

Q5. 하루에 몇 명까지 신청할 수 있나요?
  → 네이버 정책상 하루 서로이웃 신청 제한이 있을 수 있습니다.
     50~100명 단위로 나눠서 사용하시는 것을 권장합니다.

Q6. 백신/윈도우 디펜더에서 차단해요
  → exe 파일 특성상 오탐지가 발생할 수 있습니다.
     "허용" 또는 "예외 추가"로 설정해주세요.
